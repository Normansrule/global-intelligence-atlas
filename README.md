# Global Intelligence Atlas open data

Independently sourced replacements for the infrastructure lists that came from World Monitor, written monthly by `.github/workflows/open-data.yml` on main (`tools/fetch-open-data.mjs`); each run replaces the branch.

- `nuclear.json`, `spaceports.json`, `economic.json`, `minerals.json`: Wikidata (CC0 1.0).
- `ports.json`: NGA World Port Index, Pub. 150 (U.S. public domain).
- `cables.json`: TeleGeography Submarine Cable Map (CC BY-NC-SA 3.0: attribution, non-commercial, share alike).

See docs/REFERENCES.md on main for citations and terms.
