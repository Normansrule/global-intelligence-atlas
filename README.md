# Global Intelligence Atlas aircraft types

Machine-written by `tools/build-aircraft-db.mjs` (weekly, `.github/workflows/aircraft-db.yml`). 514,397 aircraft with an ICAO type code, from the OpenSky Network aircraft database (https://s3.opensky-network.org/data-samples/metadata/aircraft-database-complete-2025-08.csv). Files: `types/<first two hex digits>.json` mapping ICAO 24-bit address → [type, registration, ICAO aircraft class].
