# Global Intelligence Atlas regional data

Detailed public records boiled down for the map, written monthly by `.github/workflows/regional.yml` on main (`tools/fetch-regional.mjs`); each run replaces the branch.

- `pur/`: California Department of Pesticide Regulation, Pesticide Use Reporting, by one-mile section, chemical, crop and method.
- `usgs/`: U.S. Geological Survey Pesticide National Synthesis Project county estimates.
- `tri/`: U.S. EPA Toxics Release Inventory facilities.
- `ces/`: CalEnviroScreen 4.0 census tracts (OEHHA).
- `echo/`: EPA ECHO facilities with violations, enforcement actions or penalties.
- `wqp/`: Water Quality Portal sites with pesticide results.

See docs/REFERENCES.md on main for citations and terms.
