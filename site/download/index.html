Take the Earth with you

Two ways to install. Both open straight onto the 3D globe and keep the lessons, tours and quiz.

Desktop app

A small native window around the same globe, built with Tauri — the framework World Monitor uses for its own desktop app. Built automatically by GitHub Actions for every release.

Windows 10 and 11

Installer (.msi or .exe)

Windows may show “Windows protected your PC” because the app is not code-signed. Choose More info → Run anyway.

macOS 11 or newer

Disk image (.dmg)

Pick “aarch64” for Apple silicon or “x64” for Intel. The first time, right-click the app and choose Open, because it is not notarised.

Linux

.AppImage, .deb or .rpm

For the AppImage: chmod +x Global*.AppImage, then run it.

Why download? Browsers refuse to read flight trackers directly, so the website shows planes from a snapshot taken every 4 minutes and projects them forward. The desktop app fetches OpenSky and the community ADS-B exchanges itself, so flights are truly live (every 90 seconds worldwide, every few seconds near your view), and it runs the globe with GPU rasterisation switched on.

All builds are on the releases page with their checksums. No release yet? The repository owner creates one by pushing a version tag — see the README.

Install from your browser

Global Intelligence Atlas is a progressive web app. In Chrome or Edge, open the globe and choose Install Global Intelligence Atlas from the address bar or the ⋮ menu. On iPhone or iPad, use Share → Add to Home Screen. The pages, textures and datasets are cached so the globe, lessons and quiz open without a connection; live layers refresh when you are back online.

Open the globe to install

Run it from source

Everything is static files, so any web server works.

git clone https://github.com/Normansrule/global-intelligence-atlas.git
cd global-intelligence-atlas/site
python3 -m http.server 8080      # then open http://localhost:8080

To build the desktop app yourself you need Rust and Node.js: cd desktop && npm install && npx tauri build.
